# 005 · Retro-Terminal Visual Identity

**Status:** done

## What it does

Gives the portfolio an unmistakable, restrained 1980s workstation identity while
preserving its ink-black canvas, indigo signal, translated content, and readable CV.
The hero is presented as a terminal window, with a grid field, monospace headline,
terminal prompt, and squared controls. The CV remains an editorial document, with
subtle terminal markers on its section headings.

## Why

The previous treatment used only a small monospace kicker and section markers. Those
details were too subtle to register as the requested retro-futurist direction. The
terminal should be clear in the first viewport without turning the whole site into an
arcade or synthwave theme.

## Acceptance Criteria

- [x] The first viewport clearly reads as a retro workstation through terminal-window
  framing, restrained grid lines, monospace hero typography, and squared controls.
- [x] The existing black and indigo palette remains the only color direction.
- [x] The hero heading and kicker remain translated in English, Spanish, German,
  French, and Russian.
- [x] The CV remains readable and document-like, with its existing terminal markers.
- [x] Layout remains responsive without horizontal overflow and retains visible
  keyboard focus and reduced-motion support.
- [x] `DESIGN.md` and `.impeccable/design.json` describe the implemented visual system.
- [x] The production build succeeds.

## Out of Scope

- Synthwave gradients, arcade imagery, scanlines, flashing effects, or extra accent
  colors.
- Reworking the CV content or replacing the language selector.
