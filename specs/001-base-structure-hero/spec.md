# 001 · Base Structure and Hero

**Status:** In progress 🔜

## What it does
Defines the visual skeleton of the page (Global Layout with Navbar and Footer) and adds the first section (Hero) to welcome the user with a clean animation, my professional title, and a call-to-action button pointing to my projects.

## Why
It is the visual starting point. We need a solid structure to fit the rest of the sections and a powerful first impression for anyone entering the link.

## Acceptance Criteria
- [ ] The page is completely responsive (looks perfect on mobile and desktop).
- [ ] The Navbar includes links (even if internal anchor links `#`) to: Home, Projects, About Me.
- [ ] The Hero section displays an attractive title, a brief description, and visible links to GitHub and LinkedIn.
- [ ] The design respects the color palette defined in the constitution.

## Out of Scope
- Dynamic project loading (will be done in the next feature).
- Real functionality of the contact form.
