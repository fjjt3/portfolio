# Mission — Professional Portfolio

## What we build
An interactive, fast, and visually appealing web portfolio that compiles and highlights my most interesting GitHub projects, serving as a business card for recruiters and the dev community.

1. **Landing Page / Hero** — Impactful presentation and personal value proposition.
2. **Projects Section** — Dynamic cards connecting with the GitHub API or displaying featured projects.
3. **About Me & Contact Section** — Space for bio, technologies I master, and a direct contact form/links.

## For whom
- **Recruiters and Tech Leads:** Looking to validate my technical skills quickly and clearly.
- **Dev Community:** Other developers who want to connect or look at my code.
- **Myself:** As a practice environment to master the OpenCode terminal and modern deployment tools.

## Principles
- **Performance First:** The web must load instantly (hence choosing an SSG/Astro approach).
- **Clean and Modern Aesthetics:** Well-crafted visual design, native dark mode, and flawless responsiveness.
- **Easy to Maintain:** Adding a new project should be as easy as pushing to GitHub or updating a Markdown file.

## What it is NOT
- It is not a massive tech blog (at least in this stage).
- It is not a platform with its own database or complex backend; it is a static/Jamstack site.
